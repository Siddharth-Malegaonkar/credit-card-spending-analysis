# Credit Card Spending Analysis

## Project Overview

This project analyzes credit card transactions in India using SQL Server. The goal is to explore customer spending habits, identify spending patterns, and generate insights from transaction data.

## Dataset

- **Source:** [Kaggle – Analyzing Credit Card Spending Habits in India](https://www.kaggle.com/datasets/thedevastator/analyzing-credit-card-spending-habits-in-india)
- **Table Name:** `credit_card_transcations`

## Tools and Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Project Objectives

- Analyze total credit card spending.
- Compare spending across different card types.
- Identify cities with the highest transaction amounts.
- Explore spending patterns by expense category and gender.
- Analyze monthly spending trends.
- Identify the highest-value transactions.

## How to Run

1. Download the dataset from Kaggle.
2. Import the CSV file into SQL Server.
3. Create the database and table using the SQL script.
4. Execute the analysis queries.
5. Review the results to identify spending patterns.
